
No test suite, no lint script configured.

## Architecture

**Stack**: Astro 4, TypeScript, Tailwind CSS. Fully static output — no server runtime needed.

**Content**: Posts ("Words") are plain markdown files in `src/content/words/`, which doubles as an Obsidian vault (`.obsidian/` is gitignored). No CMS or API keys required. The filename becomes the URL slug. Posts with `published: false` get no page and are left out of the list.

**Content schema**: Defined in `src/content/config.ts` using Zod. The `slug` field is auto-generated by Astro from the filename — do not add it to frontmatter. `date` is coerced to a Date; format it with `timeZone: "UTC"` so it doesn't shift a day.

**Routing**:
- `/` → `src/pages/index.astro`
- `/words` → `src/pages/words/index.astro` (published posts, newest first)
- `/words/[slug]` → `src/pages/words/[slug].astro` (prints the title and date, then renders markdown via `entry.render()`)
- `/testimonials` → `src/pages/testimonials.astro` (reads `db/testimonials.json`, sorted by `order`)
- `/blog` and `/blog/post/<slug>` redirect to `/words` via `redirects` in `astro.config.mjs`

**Navigation**: `src/components/Nav.astro` lists Home, Words, Testimonials and Resume, minus the page being viewed. On `/`, `/words` and `/testimonials` it sits beside the page heading; on other pages `Header.astro` shows it on the right.

Everything is static Astro. The only client JS is an inline `<script>` in `index.astro` that unhides project cards in batches of 3 as the user nears the end of the list, and fades each card in as it scrolls into view (both via IntersectionObserver); all cards are server-rendered, with a `<noscript>` fallback that shows them all.

**Styles**:
- `src/styles/global.css` — Tailwind base + custom `.post-content` styles for rendered markdown, `.playfair-display` font class, and CSS `fade-in-up` animation classes.
- `tailwind.config.js` — extends with `bg-tech-pattern` background image.
- Google Fonts (Lato + Playfair Display) loaded via link tag in `src/layouts/Layout.astro`.

**Layout**: `src/layouts/Layout.astro` wraps all pages with Header, Footer, analytics scripts, and all `<head>` meta/favicon tags.

## Adding Posts

Create `src/content/words/your-post-slug.md` with:

```md
---
title: "Post Title"
date: "YYYY-MM-DD"
summary: "One sentence shown on the Words list."
tagLine: "Optional short hook line"
published: true
---

Content here (no leading # Title; the page prints it).
```

The URL will be `/words/your-post-slug`. Optional: `linkedin_url`.
